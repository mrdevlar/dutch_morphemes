### 1. Word Status: Loanword (Anglicism)
First, it is crucial to note that `workshop` is not a native Dutch word. It is a **loanword** (specifically an *Anglicism*) borrowed directly from English.
*   **Native Dutch Equivalent:** `werkplaats` (literally: *work* + *place*).
*   **Semantic Shift:** In modern Dutch, `workshop` rarely refers to a physical room for manufacturing (which is `werkplaats`). Instead, it almost exclusively refers to a **training session, interactive meeting, or creative class**.

| Morpheme | Type | Origin | Meaning | Function |
| :--- | :--- | :--- | :--- | :--- |
| **`work`** | Root (Free) | English | Arbeid / Activiteit | **Modifier** (Specifies the type) |
| **`shop`** | Root (Free) | English | Winkel / Werkplek | **Head** (Determines the category) |

*   **Compound Type:** Endocentric Compound.
    *   The word is a type of `shop` (head), specifically one for `work` (modifier).
*   **Zero Derivation:** There is no linking vowel or suffix connecting the two roots (unlike native Dutch compounds which sometimes use `-s-` or `-e-`, e.g., `bloemen` + `pot`).

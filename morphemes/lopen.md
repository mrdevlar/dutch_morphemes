### 2. Detailed Explanation

#### A. The Root: `loop-`
*   **Classification:** This is the **lexical root** (or stem). It carries the core semantic meaning of the word.
*   **Meaning:** It denotes the action of moving on foot.
*   **Linguistic Status:** In Dutch, `loop` is a **free morpheme** because it can function independently as a noun (*de loop* — meaning "the run," "the course," or "the barrel of a gun"). However, within the verb *lopen*, it functions as the verbal stem.
*   **Etymology:** It derives from Old Dutch *lopan*, which comes from Proto-Germanic *\*lupaną*. It is cognate with the German *laufen* and the English *leap* (though the English meaning shifted significantly).
*   **Phonology:** The vowel `oo` represents a long /oː/ sound. Note that in the past tense of this verb (a strong verb), this vowel changes to `ie` (*liep*), indicating that the root is subject to ablaut (vowel gradation), but the consonantal frame `l-p-n` remains stable.

#### B. The Suffix: `-en`
*   **Classification:** This is an **inflectional suffix**.
*   **Function:** It marks the verb as the **infinitive** (the citation form found in dictionaries).
*   **Grammar:** In Dutch morphology, the infinitive marker is almost exclusively `-en` (e.g., *maken*, *zien*, *gaan*).
*   **Bound Morpheme:** This suffix cannot stand alone; it must attach to a verb stem to create a grammatical verb form.
*   **Phonology:** In standard written Dutch, it is pronounced as a schwa /ə/ (e.g., /loːpən/). However, in many spoken dialects and informal registers, this vowel is elided (dropped), resulting in a pronunciation closer to /loːpŋ/ or simply /loːp/. Despite this phonetic reduction, morphologically it is still analyzed as the suffix `-en`.

### 3. Morphological Classification
*   **Word Class:** Verb.
*   **Derivation vs. Inflection:** The word `lopen` is an **inflected form** of the lexeme *lopen*. It is not a derived word (like *loopster* "female walker," which would add a derivational suffix *-ster*).
*   **Verb Type:** It is a **strong verb** (sterk werkwoord). This is relevant to morphology because the root vowel changes in the past tense (*loop* → *liep*), whereas weak verbs add a dental suffix (*-te* or *-de*) without changing the root vowel.
